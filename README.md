# SecretCodeLanguage
This program is a very basic level encryption, it follows the following rules :
=> Encoding
1) If the word has 3 or less than 3 characters, reverse it.
2) If it has more than three characters, then place the first letter of the word at the end, and adding three
random characters at the starting, and three random characters at the end.

=> Decoding
1) If the word has 3 or less than 3 characters, reverse it.
2) If it has more than three characters, then remove the first 3 and last 3 random characters, and place the
last letter to the first place.
